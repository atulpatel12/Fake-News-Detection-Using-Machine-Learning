# Fake-News-Detection-Using-Machine-Learning
A machine learning model built in Python to classify news articles as **Real** or **Fake**.

## 📌 Features
- **Dataset:** Kaggle FakeNewsNet dataset (~23,000 articles)
- **NLP Preprocessing:** Stemming using `PorterStemmer`, removing English stopwords, and feature extraction via `TfidfVectorizer`.
- **Classification Model:** Logistic Regression classifier.
- **Accuracy:** 
  - Training Accuracy: ~88.2%
  - Testing Accuracy: ~85.2%
